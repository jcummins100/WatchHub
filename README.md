# WatchHub for Kodi

One home screen for live sports, free live TV and your streaming services, built for Kodi 21 on Android TV (NVIDIA Shield).

- `plugin.video.sportshub` – the WatchHub add-on (guide data, scores, catalog, Trakt, launcher)
- `skin.sportshub` – the WatchHub skin (based on Estuary)
- `repo/` – Kodi repository for automatic updates
- `tools/` – build, deploy and import scripts

WatchHub contains no streams. Everything plays in the official apps with your own accounts.

## Install with automatic updates

In Kodi: Settings → File manager → Add source → `https://raw.githubusercontent.com/jcummins100/WatchHub/main/repo/` is not browsable, so install the repository zip instead:
download `repo/repository.sportshub/repository.sportshub-1.0.0.zip`, then Settings → Add-ons → Install from zip file.
